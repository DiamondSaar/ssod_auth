# Кабинет юридического лица (`/account/org/`)

Отдельная зона личного кабинета для клиента-организации. Вход выполняется
**обезличенной учётной записью организации** (например `ascom-lk`), а не
учётной записью сотрудника. После входа открывается мониторинг инфраструктуры
этой организации; личных разделов (продукты, ключи, репозиторий, безопасность)
у такой учётной записи нет.

## Как устроено

- **Признак учётной записи** — `CustomUser.is_organization_account` (локальный
  флаг, редактируется в админке). Организация берётся из Dominex при каждом входе.
- **Разделение зон** — `accounts.middleware.OrganizationCabinetMiddleware`:
  любой адрес в `/account/`, кроме `/account/org/`, возвращает такую учётную
  запись на её страницу. Правило одно на все разделы, поэтому новый личный
  раздел не станет дырой в разделении. Сотрудники ССОД (`is_staff`) под правило
  не попадают — им нужна админка.
- **Мониторинг** — та же страница, что у руководителя-физлица
  (`accounts/infrastructure.html`, данные из Dominex по `build_summary`).
  Различается только колонка переходов: шаблон подставляет `_org_nav.html`.
  Dominex определяет организацию по самой учётной записи, поэтому чужие данные
  показать невозможно даже при подмене адреса.
- **Документы** — `/account/org/documents/`, пока заглушка.
- **Связь** — `/account/org/contact/`: письмо на `ORG_SUPPORT_EMAIL` и сообщение
  в канал поддержки Dominex Vox (`VOX_SUPPORT_WEBHOOK_URL`). Успех — если ушло
  хотя бы одним путём.

## Подключение новой организации

1. **В Dominex** завести обезличенную учётную запись (например `spa-lk`):
   карточка физлица с этим именем, привязанная к нужной организации, плюс
   пароль. Dominex — хранилище паролей и источник истины по организациям.
2. **В кабинете** выполнить команду:

   ```bash
   cd /opt/ssod_auth
   docker compose exec -T ssod_auth_web python manage.py setup_org_account --username spa-lk
   ```

   Команда заводит локальную запись, подтягивает организацию из Dominex
   и включает режим кабинета юрлица. Выключить режим — тот же вызов с `--off`.
3. Передать клиенту логин и пароль. Адрес входа общий:
   `https://auth.ssod.pro/account/login/`.

Проверка: под учётной записью организации `/account/` и `/account/products/`
должны возвращать на `/account/org/`, а на странице мониторинга слева — колонка
«Кабинет организации» без личных разделов.

## Настройки

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ORG_SUPPORT_EMAIL` | Куда уходит письмо с обращением | `info@ssod.pro` |
| `VOX_SUPPORT_WEBHOOK_URL` | Входящая интеграция Vox (канал поддержки) | пусто — тогда только письмо |
